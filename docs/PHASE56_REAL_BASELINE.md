# Phase56 Real Chart Baseline

This workflow measures the current read-only Chart Intelligence baseline on real historical daily candles fetched during GitHub Actions from Yahoo Finance's public chart endpoint.

Current basket: 7203.T, 6758.T, 9984.T, 8306.T, 8035.T. Range: 5y. Interval: 1d. Horizons: 1/3/5/10/20 bars.

Outputs: sample count, directional hit rate, mean aligned return, and per-symbol profit factor. This is a baseline diagnostic, not a trading recommendation, not a probability forecast, and not authorization for paper or live execution.
