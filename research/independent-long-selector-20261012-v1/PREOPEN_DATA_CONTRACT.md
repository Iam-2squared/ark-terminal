## Private stage order

1. Metadata-only session reconciliation and current use basis.
2. One original stream into SQLite, exact source checkpoint and access receipt.
   Non-admitted rows are lexically traversed and counted; their numeric prices
   are not parsed or emitted. Original gzip is never recompressed as an original.
3. Per-row calculations into float64 columnar shards with shared history in
   SQLite. Long price history is not duplicated into every persisted snapshot.
4. Fit/calibration only, model/hash/schema frozen, then all Report watchlists.
5. Report source descriptor is read and outcome prices parsed, then evaluation.
   The terminal Report day's prices are not numerically admitted as features.
   Earlier Report prices may be valid D-1 history for a later Report snapshot;
   this exposure is recorded and is not called wholly unopened.
