LOW/HIGHはraw-score median domainではない。

各head h:

T_h =
そのcandidateのrolling-origin blockに対応する、
head hのcompleted-past training reference score population。

s_h =
current candidateのcausal score。

rank numerator:
1 + count(t in T_h where t < s_h)

rank fraction:
r_h =
(1 + count(T_h < s_h))
/
(|T_h| + 1)

LOW_h iff:

2 * (1 + count(T_h < s_h))
<
|T_h| + 1

HIGH_h:
NOT LOW_h
