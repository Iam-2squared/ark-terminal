# Revised G7 protocol — DRAFT FOR HUMAN REVIEW, NOT EXECUTED

The original G7 v1 remains FAIL. This draft changes the review apparatus, not State numeric rules. The current 36 corrected cases are exposed regression fixtures; neither replay nor another review of them is a fresh G7 pass.

## Required before distribution

Hash-lock the exact rule brief, candidate spec, reference module, producer, renderer, schema, scorer, sample manifest and control key. Prove actual cards use normalized barEnd/knownAt cutoff and independently rebuilt CLOSED_PREFIX NOW. A future-suffix perturbation must leave their semantic sidecar, HTML and PNG hashes unchanged. Include the complete rule brief and numeric witnesses with every reviewer pack.

Separate technical conformance (exact fixed rules) from subjective semantic adequacy. Do not hide a genuine rule mismatch behind a new label or compensate by adjusting thresholds.

## Sampling proposal

Retain the prior budget of 36 actual cases and eight control targets; no enlargement into a new State taxonomy study. Draw actual cases from already-authorized Development only, using a precommitted seed and status-cell strata with fixed time/price bins. Exclude the old exposed cases from the independent denominator. Do not filter on lateConfirmedPivots or any future outcome. If a rare cell cannot supply a new case, report the shortfall and seek a disposition before sampling; do not silently relabel a reused fixture as independent.

No actual/control near-duplicate price paths. A synthetic control's truth must follow from the supplied fixed contract and visible witness fields, not comparison with another card.

## Blinding and independence

Two fresh reviewers, not this authoring context and not the differential Freeze-review session. No shared verdicts before both submissions are frozen. First pass: evaluate the causal witnesses using the provided rule brief without the candidate's axis labels. Freeze expected axis responses. Second pass: reveal displayed candidate outputs and record defects. Both stages and any INDETERMINATE response are retained. LLM correlation remains a limitation; this is not objective market truth.

## Distinguish two case contracts

NOW-conformance cases are NOW-only, including any deliberately forbidden-field control. Future-evaluator contract cases are explicitly headed EVALUATOR-ONLY and must never enter a NOW artifact. A future censor control must show enough evaluator witness information to identify both failed premises. Merely noticing a Future card is not proof of detecting a collapsed censor bit.

No Future evaluator result is returned to the NOW feature set, used for sampling, or used for model fitting in this gate.

## Proposed response and scoring contract

For each case preserve:
- expected axis response from the blind first pass;
- `representationDefect` (YES/NO/INDETERMINATE);
- explicit `defectCodes[]` and short numerical/rule rationale;
- `inputLimitationCodes[]` independently of representationDefect;
- `semanticAdequacyConcern` separately from technical conformance.

Observation absence honestly labeled must not automatically create representationDefect. The control key pins the intended defect code plus its witness predicate. Correct target-specific detection is required; a generic issue tag is insufficient. Duplicate case IDs, missing cases, illegal codes, contradictory fields or empty rationales invalidate a submission.

Retain the old acceptance thresholds, not soften them after failure: both reviewers must detect every intended control defect (8/8 each); actual-case kappa>=0.60; only when kappa is undefined, raw agreement>=85% and both control requirements. Report confidence limitations and full disagreement table. Any actual temporal leakage hard-fails. An unresolved blocking vocabulary gap is not patched into v2.0 from the same review set.

This is a protocol proposal. No new seed/sample, new blind run, independent review, State v2 Freeze or Acceptance is claimed by this document. Human approval of the revised protocol precedes those actions.
