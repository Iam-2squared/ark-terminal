# ARK — PULLBACK + SHARP_DROP Entry候補除外：研究基準Freeze（2026-10-08）

**凍結した決定**：新研究では、Entry時点で正式に利用可能なState9 Primaryが `PULLBACK` または `SHARP_DROP` なら、その候補を**一律に除外**する。初回購入だけでなく、売却後に合法約定で空いた枠、Slot2/3、同時刻batch、資金再利用で購入する候補も**同じ条件で除外**する。除外したEntry IDを空き枠で復活させない。
