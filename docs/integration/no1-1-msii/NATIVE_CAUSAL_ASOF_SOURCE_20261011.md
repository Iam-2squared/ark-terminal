# No.1.1 Native live bridge, stage 1 — causal source observation boundary

The original No.1.1 research Freeze is an immutable policy/source pointer, NOT an executable real-time Selector/State9/Entry/EXIT decision producer. Public V5 core_features.py at pinned commit 710656491be06235901b45c50a8b5cbd714ba4eb (blob 685a7774ed96556b810aa23957d12fda8f9654ba) uses saved original model predictions and a State9 path prefix with entry intent/fill timing features. Thus model hash verification alone does not prove that every necessary input was available before a potential live BUY/SELL decision. Replaying historical EXIT suffix, teacher labels or after-fill fields as pre-decision evidence would be lookahead.

native_causal_asof.mjs validates observational sources with full timezone-bearing timestamps and ascending as-of / observed / known / decision-time relations, closed bars and duplicate IDs. Future labels/teacher/outcomes and assertions of native model or broker delivery certification are rejected. No model score is calculated, and the accepted observation frame is deliberately marked SOURCE_OBSERVED_ONLY; its SHA256 is an integrity fingerprint, not a trusted brokerage receipt. The module is pure/O(n), with no wait, no per-tick filesystem read, no extra human switch, no order method and no user account access.

This is a preparation for a future real MarketSpeed II market read-only observation feed and the original native inference runtime. Original Frozen Entry excludes PULLBACK and SHARP_DROP and the first legal SELL fill stops subsequent BUY in the session. Those rules remain enforced separately in the existing Locked intent and Safety lineage; this module cannot issue Entry or EXIT.

Remaining physical certification: real provider data receipt time, original H2/H3/H5 input feature computation, private saved model install, State9 and native First Entry/EXIT event emitter and validated broker order/fill/cash reconciliation. Excel order permission stays OFF; live orders/transmission disabled, frozen/main untouched.
