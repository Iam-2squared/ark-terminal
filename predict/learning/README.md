# Prediction Lab learning layer

このフォルダは、Prediction Labの予測ロジックと、予測後の検証・改善ロジックを分離するための層です。

## データの流れ

1. `feature-extractor.js` が予測時点の指標値と発生条件を固定保存する
2. `backtest/storage.js` が予測と後日の実績を保存する
3. `analytics.js` が指標・組み合わせ・業種・相場環境ごとの成績を集計する
4. `analysis/weights.js` が学習期間だけから推奨重みを計算する
5. ユーザーが推奨重みを確認して採用した場合だけ次回予測へ反映する
6. `dataset.js` が将来の機械学習向けに特徴量と正解ラベルを分離して出力する

## 未来情報の混入防止

- 特徴量は予測作成時点で保存する
- 実際の騰落率は `label` として別に保存する
- 学習、検証、最終テストは時系列順に分離する
- 推奨重みの算出には学習期間だけを使う
- 検証・最終テストの成績は重み調整へ混ぜない

## 現在の方式

現在はルールベースです。重みは自動適用せず、AI Performanceに「推奨重み」と根拠件数を表示します。
LightGBM、XGBoost、CatBoostなどを追加する場合は、`dataset.js` の出力を入力契約として利用できます。

## 注意

検証件数が増えると推定のばらつきは小さくなりますが、勝率や利益が必ず上がるわけではありません。
相場環境の変化、サンプルの偏り、過学習、データ遅延は残ります。この機能は分析・検証用であり、売買を保証または自動実行しません。
