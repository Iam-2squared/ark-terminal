# Phase56.5-56.7 Pattern Intelligence

Classic chart-pattern names are treated as research hypotheses, not trading truths.

## 56.5 Pattern quality / false-positive reduction
Pattern candidates are required to expose explicit geometry and later validation can reject weak candidates. A named pattern never implies a recommendation.

## 56.6 Classic pattern engine
The first deterministic candidates use swing geometry rather than screenshots: ascending/descending/symmetrical triangles, double-top/bottom candidates, and rising/falling wedge candidates. These definitions are intentionally testable and replaceable.

## 56.7 Context integration
Pattern geometry is combined with descriptive volume, VWAP alignment, setup context, and market-regime context into a research-only quality score. This score is not a probability and is not evidence of profitability.

## Evidence policy
No classic pattern is trusted because a chart book or website names it. Phase56.8 must measure each detector chronologically out of sample by market, timeframe, regime, liquidity and forward horizon. Detectors that do not demonstrate stable OOS evidence should be down-weighted or retired.

## Safety
Recommendation, paper trading, broker/Excel/RSS writes, live trading, automatic promotion, production updates and execution remain disabled.
