# No.1.1 RSS買付可能額 → 通常LIVE資金接続（2026-11-03）

旧Operational/EXIT ZIPは使いません。11/3 Clean Rebuild適用済み本体が対象です。

## 今回の実装

- `fundingPolicy=RSS_BUYING_POWER` を明示した通常LIVE設定では、開始時の実RSS買付可能額をそのまま開始予算として採用します。銀行・スイープの再確認、別の現金画面証拠、余力更新証拠ファイルを要求しません。
- 初回だけ開始額を保存し、同一セッションの再起動で再加算しません。注文拘束・約定・売却による台帳更新と、その後のRSS利用可能額の上限は従来どおりです。
- 原本モデル・Selector・Capital V5・Structural EXITを変更せず、一般口座・現物・通常MAX3・100株・ZERO/SORを使用します。
- 起動時に既に保有している株はARK所有へ取り込みません。既存の手動売却・個人保有・混在時の保護を維持します。
- 当日の明示承認、応答不明時の再送禁止、観測取得失敗時の停止は残します。Shadowや1銘柄限定の本番運用は追加しません。
- RSS値の採用と配信元の更新証明は区別します。既存の `buyingPowerFreshnessCertified=false` は勝手にtrueへ変えません。内部の30秒観測時刻チェックは、古いファイルや停止した監視の使用を防ぐものです。

資金表示もRSS採用モードに対応し、別画面の現金審査済みという誤表示は行いません。

## インストール

ARKランチャー・売買エンジン・口座監視を終了します。Excel/MSIIはこのインストーラーから操作しません。
ZIPを新しいフォルダーへ展開し、その中で次を実行します。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-No11RssFunding.ps1 -Apply
```

変更対象5ファイル＋追加3ファイル。変更前に全対象を照合し、バックアップします。
週次/UIの独自変更を含むランチャーは、資金チェックの一意なコード部分だけを変更します。
その他の対象が想定ソースと異なる場合は上書きせず停止します。Git reset/checkoutはしません。
インストーラーは設定をLIVE化せず、売買を起動せず、口座台帳も作成しません。

## 設定生成ツール

本体の `tools/no11_make_rss_live_config.py` は、実際の入力パスと当日の物理発注設定から、既存形式のBootstrap/Broker設定を生成します。
`--spec` のJSONには `bootstrapInputs`, `transport`, `originalArrivalTable` が必要です。
未確認の銘柄マスター・過去日データ・Excel識別子を推定・偽造しません。
新しい設定ファイルを生成するだけで、ランチャー設定への登録や注文送信はしません。
起動時は従来の当日承認スイッチが必要です。

## このパッケージだけでは終わらない部分

実機の当日マスター/対象銘柄/前日Contextと物理発注設定の自動生成、生成したBootstrapのランチャーへの登録は別の接続作業です。
このZIPのインストール完了を「通常LIVEの全自動起動完成」「実BUY/EXIT成功」と読み替えないでください。
停止は、既に証券会社へ送った注文の取消や保有の売却を意味しません。
実売買の不具合時は、合意済みの手動注文・保有確認で対応します。

自動テストは開発環境内の合成データ・モックです。実口座でのShadow運用や限定注文を前提条件として要求するものではありません。
